**Goal:** 掉落查询（`crafting/loot.py` 的 `find / _wiki_classes / mine_info / detail` 取版本）改走 `sc_mining/gamedata`，删掉查询路径上读 `loot_index.json`、`wiki_items.json` 的代码；掉落明细（`loot_details.zip`、`data/loot/`）照旧按需读文件；对外行为、文本输出一个字不变。

**Tech Stack:** Python 3.12 标准库；`tests/minipytest`。

**Spec:** 设计文档 v3；矩阵 `docs/superpowers/specs/2026-11-02-gd-b4-callsites.md`；地基 API `sc_mining/gamedata/__init__.py`；topic 写法范本 `sc_mining/gamedata/shops.py`（`_ready.use(snap)` + `_cache.VersionCache`）。
