AT 星际公民助手（Astral Toolkit，免费软件）

安装（推荐：安装版，不用装 Python）：
  1. 下载 AT-win-Setup.exe（国内：https://at-dl-1323647399.cos.ap-guangzhou.myqcloud.com/releases/v1.1.3/AT-win-Setup.exe ；
     海外：https://dl.astral-trade.com/releases/v1.1.3/AT-win-Setup.exe 或 GitHub 发行版），双击安装（不需要管理员权限，装在「AppData\Local\AT」）。
  2. 运行安装程序时 Windows 可能弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
     AT 是免费的个人作品，没有购买数字签名证书，所以 Windows 不认识它；杀毒软件拦截时添加信任即可。
  3. 以后有新版本，AT 会提示；在「设置与更新」点「下载并升级」，自动下载、安装并重新打开，设置和记录都保留。

使用：
  从桌面或开始菜单打开 AT。第一次打开要阅读免责声明，并自己打字输入「本软件是免费软件」。
  Windows 会弹「是否允许」确认框，点「是」（游戏是管理员权限运行的，不点的话热键用不了）。
  游戏请用「全屏」或「无边框窗口」模式：悬浮窗才看得到，F8 物品识别、扫描面板、信号识别读的是游戏画面，窗口模式位置不准。

窗口左边的功能：
  概览：首页。上面的搜索框能搜物品、地点、矿、蓝图和维科洛兑换。
  采矿助手：挖矿时实时读屏。雷达信号直接告诉是什么矿、几块；扫描石头后给破碎方案（用哪个矿头、功率开多少）、
        精炼后能拿到多少、值多少 aUEC、建议的精炼方式和站点。支持鼹鼠 MOLE、勘探者、魔像，配置可以自己改。
        矿头是用蓝图自己造的：配置里把「来源」选成「自己造的」，填发射器（萨达瑞晶）和汇流排（铜）的品质，按自造的功率算。
        结果下面的「成分」表：石头里每一份（同一种矿的高低品质分开、惰性物质）占多少、多少 SCU、品质第几档、精炼后多少。
        读不全时会提示原因（比如面板被屏幕右边挡住、字有色差重影），照提示改一下游戏设置就行。
        切到别的窗口（聊天、浏览器、AT 窗口）时自动暂停识别，切回游戏自动继续。
  制造：制造蓝图要什么材料、蓝图从哪来；每个材料槽拖滑块定品质，马上看成品属性「基础 → 强化 → 变化」（几个槽影响同一属性时相加）；
        标签带尺寸（S1/S2…）、等级、类别；可以按矿反查能做什么；混料计算（省高品质料、合并零散箱子）。
  导航：导航到没有量子信标的地方（洞穴、残骸、自定义路标），悬浮窗按机头提示「右转多少度、抬头多少度」，太空里也能用；
        还有小行星带导航（从哪跳、HUD 剩多远时按 U 断开）。
  物品查询：搜物品和矿物——中文、英文、名字的一部分都能搜（比如「视差步枪」），游戏里有的物品都能搜到（商店、掉落、汉化包、英文 wiki 清单一起搜）；在哪买、掉落、玩家市场价；
        商店和掉落数据里都没有的东西（任务奖励、活动、涂装等）也搜得到，会注明；每件物品带游戏内说明；矿物在哪挖、能做哪些蓝图。
  维科洛兑换：每个兑换要交什么、每样材料去哪弄。
  库存：按地点和仓位记下手里的东西（地点从游戏里的空间站、城市列表里选，默认是游戏里最后打开库存的地方；
        每个地点下面可以自己分仓位）。能出库、改数量、移库、改品质，每笔可以写备注；「仓储流水」能按日期、类型、地点查，
        记错了能撤销；每样东西被目标清单占用了多少、大概值多少 aUEC 也看得到。
  目标清单：设好要换的兑换或要造的东西，按库存算还差什么、去哪弄、大概多少钱；造东西时拖材料品质滑块（默认按分到的库存平均品质），看成品属性会变成多少。
        做好了点「做完了」，自动从库存扣掉用掉的材料。

游戏里的热键：
  F8：鼠标指着物品按一下，直接打开它的买点、掉落和价格（说明框里有品质会一起读出来）。这个键可以在「设置与更新」里换。
  记录路标、一键定位：默认不绑键，要用到「设置与更新」→「热键」里自己设（按下后自己在聊天框输入 /showlocation 回车，AT 读剪贴板里的坐标）。
        不绑键也行：记录路标就自己输入 /showlocation，再到「导航」→「我的路标」点「粘贴」；一键定位时自己输入 /showlocation 回车，AT 会自动接住。
  F10：识别不到或认错时按一下，把当时的截图和数据存下来并自动发给作者（设置里能关；关了就在「问题反馈」里导出）。

地面导航要读游戏右上角的坐标：游戏里按 ~ 打开控制台，输入 r_DisplayInfo 2 回车。
新建路标也可以自己在聊天框输入 /showlocation，坐标会复制到剪贴板，到「导航」→「我的路标」点「粘贴」，起个名字保存。

数据：第一次用会自带一份数据；在「设置与更新」里点「开始更新」可以更新到最新。
设置、路标、目标清单、日志都放在「AppData\Local\AT_userdata」（压缩包版在 userdata 文件夹），升级和卸载都不会动它。
